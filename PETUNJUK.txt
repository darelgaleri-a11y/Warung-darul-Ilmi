Penting:
- Jangan jalankan migration Guest Checkout v2 lama secara manual di produksi. Gunakan migration baru `202611180003` melalui `supabase db push`.
- Migration baru tidak menghapus data pesanan. Migration menambahkan kolom hash token dan mengganti fungsi RPC agar menerima 8 parameter.
- Token 64 karakter dari frontend divalidasi; database hanya menyimpan hash SHA-256 token.
- Fungsi hash memakai `extensions.digest` (pgcrypto). Jika migration ditolak karena fungsi/schema tidak tersedia, hentikan dan kirim error. Jangan menyimpan token mentah sebagai jalan pintas.
- Tidak ada perubahan Edge Function sehingga tidak perlu deploy Edge Function.
- Setelah migration berhasil, lakukan satu pesanan uji dari pelanggan dan pastikan muncul di antrean kasir.
